# Sistema Cobra Flex

**URL**: https://marcos-rodrigues-cobra-flex.onrender.com/

## Versão

Software de gestão para análise em o uso do combustível etanol e gasolina e suas respectivas variações de preços. O usuario irá acessar o aplicativos por meio de sistemas desktops ou mobile, fazendo uso ou não de acesso a internet para gerar o processo de análise compensatório de uso de um dos dois combustíveis utlizados em carros que utilizam o sistema Flex. Ou seja, carros com combustão a Etanol e Gasolina simultaneamente. 

## Tecnologias utilizadas: 

Software foi desenvolvido em Linguagem *Python* versão 3 e *HTML* para marcação de texto e css como folha de estilo, o compilador dos códiso *VSCode* e Navegadores *Chrome*, *Firefox* e *Edge* para visualização dos arquivos *Index.html* e com uso das seguintes bibliotecas:

## Como instalar e rodar: 
O software roda direto no navegador(Browser) de sua escolha fazendo acesso direto ao link disponilizado pelo seguinte endereço:
[https://marcos-rodrigues-cobra-flex.onrender.com/] , não necissitando da sua instalação.

## Como usar: 

Ao acessar a pagina [https://marcos-rodrigues-cobra-flex.onrender.com/] o usuario irá notar uma interface amigável onde terá nome do programa e logo abaixo dois campos de inserção dos respectivos valores do Etanol em seguinda Gasolina. Fazendo a inserção de ambos os valores podendo digitar ou mesmo colar dados provenientes de outros locais ou programas, fazendo uso de ou não de divisão por vírgula. Em seguida o usuario notará a presenção de um botão na cor verde com o dizer: CALCULAR.
Clique sobre o botão calcular e o mesmo informará se é mais vantajoso para o usuário o uso do combustível Etanol ou uso do combustível Gasolina. Ápos o programa informará com uma frase: "Melhor abastecer com Etanol" caso seja vantajoso para valor, caso a mensagem seja: "Melhor abastecer com Gasolina" caso seja mais vantajoso o uso do combustível a Gasolina.
